# GRAIL research artifact package — v1.0.0 (DRAFT)

**Status:** Proposed release notes; do not publish as an issued release until tagged.

This first public research artifact release accompanies Mike Amundsen's manuscript
*Bounded Autonomy Through Environmental Composition: An Experimental Study of the GRAIL Runtime* (manuscript v1.8).

The repository provides six experiment families (E1–E6), eleven recorded scenario executions,
original evidence archives, a scenario evidence index, reproduction reports, and setup instructions.

**Scope of evidence:** The experiments demonstrate feasibility and identify boundaries.
They do not establish guaranteed termination, verified external effects, general optimality,
lower operating costs, or clean-room reproducibility. E2's exact historical local runtime
revision is unknown. E4's cyclic execution exceeded a three-second observation window.

**Preservation:** Original experimental archives are retained unchanged. E4 logs include
historical machine paths with author approval. Reproduction results are labeled separately.
